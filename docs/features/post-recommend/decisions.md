# Decisions (ADR) - Post Recommend

### [ADR-001] 본문 네이티브 버튼 `.click()` 위임 방식 채택
- **배경**: 디시인사이드는 추천 요청 시 비회원 토큰/식별자, 갤러리 ID, 게시글 번호, 로그인 세션 쿠키, 중복 추천 검증, 자체 alert 레이어 등 복잡한 내부 로직을 거침. 직접 Ajax `POST` 요청을 흉내내는 것은 토큰 파싱 실패나 DC 측 스크립트 변경 시 취약함.
- **결정**: 본문의 실제 추천 버튼(`button.btn_recom_up`)을 탐색하여 `.click()` 이벤트를 합성/트리거함.
- **영향**:
  - 디시 공식 추천 로직과 100% 동일하게 동작하며 사이드 이펙트가 전혀 없음.
  - 중복 추천 시 디시의 "이미 추천하였습니다" 처리도 자연스럽게 처리됨.

### [ADR-002] 추천 수 실시간 반영 및 옵저빙
- **배경**: 디시인사이드 추천 버튼 클릭 후 비동기 Ajax 응답이 도착하여 DOM의 추천 수(`<p class="up_num">`)가 갱신되기까지 수백 ms의 지연이 발생함.
- **결정**:
  - 클릭 즉시 버튼 펄스 효과와 함께 토스트 피드백 표시.
  - 400ms, 1200ms 주기로 추천 수 엘리먼트를 재조회하여 갱신된 최신 카운트를 뷰어 버튼에 즉시 동기화.
- **영향**: 사용자에게 즉각적인 시각 피드백을 제공하면서 정확한 최신 추천 수가 반영됨.
