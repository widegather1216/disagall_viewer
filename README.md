# 🖼️ 디시 사진 뷰어 (Disagall Viewer)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)
[![Manifest V3](https://img.shields.io/badge/Chrome-Manifest_V3-green.svg)](manifest.json)

디시인사이드(DC Inside) 디지털 사진 갤러리 및 모든 갤러리 이용자를 위한 **화면 맞춤 몰입형 원본 사진 감상 Chrome 확장 프로그램**입니다.

사진을 우클릭하여 **"📷 디시 사진 뷰어로 화면 맞춤 보기"** 선택 한 번으로, 잘림 없이 원본 화질 그대로 사진을 몰입해서 감상할 수 있습니다.

---

## ✨ 핵심 기능

- 🖼️ **절대 사진 잘림 없는 화면 피팅**: 세로 사진(Height 100%), 가로 사진(Width 100%) 비율 자동 맞춤
- 🔍 **마우스 휠 & 트랙패드 핀치 확대/축소 (Zoom & Pan)**: 최대 5배(500%)까지 자유 확대 및 마우스 드래그 이동
- ⚙️ **실시간 여백(패딩) 조절**: 상단 슬라이더로 패딩 크기(0px~100px) 실시간 변경
- ⚡ **본문 지연 로딩(Lazy Loading) 및 원본 화질 자동 추출**: 스크롤 없이 즉시 모든 본물 원본 사진 100% 탐색
- ⌨️ **방향키 감상**: `←`, `→` 키 및 `ESC` 키 조작
- 🛡️ **100% 개인정보 보호**: 어떠한 개인정보나 브라우징 기록도 수집하지 않는 로컬 오픈소스

## 🛠️ 수동 설치 방법 (개발자 모드)

1. 이 리포지토리를 클론하거나 ZIP으로 다운로드합니다:
   ```bash
   git clone https://github.com/사용자아이디/disagall_viewer.git
   ```
2. Chrome 주소창에 `chrome://extensions` 입력 후 접속합니다.
3. 우측 상단의 **'개발자 모드'** 토글을 켭니다.
4. **'압축해제된 확장 프로그램을 로드합니다'** 버튼을 클릭하고 해당 폴더를 선택합니다.
